## Практична робота 5: Кластерний аналіз рукописних цифр
**Тема:** Некерована кластеризація зображень рукописних цифр (`load_digits`, 1797×64) методами K-Means, ієрархічної кластеризації, DBSCAN і t-SNE.
У роботі виконано:
- кластеризацію K-Means (`K=10`, ARI = `0.6687`, Silhouette = `0.1825`, візуальне вгадування центроїдів `10/10`);
- ієрархічну кластеризацію `AgglomerativeClustering` (`Ward`, `K=10`, ARI = `0.7940`, Silhouette = `0.1785`);
- порівняння `KMeans` після `StandardScaler` (`ARI = 0.4780`), `KMeans` на карті `t-SNE` (`ARI = 0.8891`) та `DBSCAN` на карті `t-SNE` (`eps=2.5`, 19 груп, 98.7% охоплення, `ARI = 0.8863`);
- оцінювання економії бюджету розмітки: при `B=10` кластерний підхід дає `0.7796` (пікселі) і `0.7752` (t-SNE) проти `0.4524` навмання; при `B=100` — `0.9727` проти `0.9015`;
- виконання всіх 6 індивідуальних варіантів (стандартизація, підстилі цифр, `linkage`, мисливець за аномаліями, `PCA` + K-Means, стратегії вибору 30 картинок для підпису).
